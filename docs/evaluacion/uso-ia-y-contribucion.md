# Declaración de apoyo de IA y contribución individual

## Uso de herramientas — declaración del trabajo observado

Se utilizó OpenAI Codex en esta conversación como asistente para inspección de
código, implementación del panel administrativo, generación/ampliación de pruebas,
revisión de contratos, corrección de documentación/modelos y auditoría técnica.
También asistió a la lectura del PDF oficial mediante pypdf y al contraste con
las fuentes del repositorio. No se atribuye una versión de modelo no acreditada.

Se verificaron las propuestas con pytest/cobertura, Node, Ruff, mypy, recorrido
HTTP local, migración de una copia y hashes de las bases. Se distinguen las
comprobaciones automáticas de la aceptación visual, instalación limpia, render
y CI que no se ejecutaron. Los resultados están en la matriz final.

Esto responde al PDF p. 10. No sustituye la responsabilidad del equipo: cada
estudiante debe revisar, explicar y poder modificar lo presentado. Este documento
no acredita que ya lo haya hecho ni es una reflexión firmada por sus integrantes.
No se enviaron mensajes, PR, commits ni publicaciones en nombre del equipo.

## Registro que debe completar personalmente cada estudiante

Para el apartado de evidencia individual del PDF p. 8, cada integrante debe
entregar un registro propio que incluya los siguientes campos:

| Campo requerido | Evidencia aceptable | Estado del cierre |
|---|---|---|
| Identidad del integrante | Nombre y cuenta GitHub que el estudiante confirme | No se asigna por el asistente. |
| Funcionalidades/componentes concretos | Rutas de archivos y explicación de su aporte | Pendiente de declaración individual. |
| PR/commits u otra evidencia verificable | URL y SHA reales, revisión o documento atribuible | PR #2 disponible; completar según cada aporte. |
| Decisión o problema resuelto | Explicar alternativas, elección y consecuencias | Pendiente de reflexión personal. |
| Pruebas/documentación desarrolladas | Nombre de prueba/archivo y resultado reproducible | Relacionar con la matriz sin inventar autoría. |
| Reflexión breve | Lo aprendido, dificultades y responsabilidad asumida | Debe redactarla el estudiante. |

No se rellenan porcentajes, horas, firmas ni aprobaciones ficticias. Conservar
evidencias reales del uso de IA y citar fuentes externas cuando corresponda.
