# Entrega final — UniShort QR

Evaluación Sumativa 1 · Universidad Nacional de Loja · **6 de noviembre de 2026**.

UniShort QR transforma direcciones académicas extensas en enlaces cortos y QR.
El incremento incorpora persistencia, estados/caducidad, métricas y un panel
administrativo sobre la API FastAPI existente. No implica integración institucional.
